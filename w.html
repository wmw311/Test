1海水的物理性质

1.1 三大基本要素

要素符号单位测量方法
温度T / θ°C (ITS-90)温度计、CTD、XBT
盐度Sg·kg⁻¹ (PSS-78 → TEOS-10 绝对盐度 S_A)电导率法、盐度计
压力pdbar (1 dbar ≈ 10⁴ Pa)应变式/压电式传感器
  • 世界大洋平均盐度 ≈ 34.7 g/kg
  • 开放大洋盐度范围：约 33–38 g/kg
  • 影响盐度的四大因素：蒸发、降水、河川径流、海冰冻融

1.2 海水状态方程（EOS）

  • EOS-80（1980）：非线性，含 T、S、p 乘积项
  • TEOS-10（2010）：以绝对盐度 S_A、保守温度 Θ 替代实用盐度/位温
ρ ≈ ρ₀ − α·ρ₀·(T−T₀) + β·ρ₀·(S−S₀)
  α = 热膨胀系数（0°C ~5.3×10⁻⁵ K⁻¹；20°C ~2.6×10⁻⁴ K⁻¹）
  β = 盐收缩系数（~7.4–7.9×10⁻⁴ kg·g⁻¹）

1.3 位温与位密

  • 位温 θ：海水绝热上升到海面所具有的温度（扣除压缩增温）
  • 位密 ρ_θ：位温对应密度，消除压力影响后用于比较不同深度的水团
  • 常用等压面：σ_θ（0 dbar）、σ_2（2000 dbar）、σ_4（4000 dbar）
  • σ_t = ρ − 1000（kg·m⁻³）

1.4 其他物性

  • 比热：约 3990 J·kg⁻¹·K⁻¹（远大于空气，海洋是热"惯性库"）
  • 黏性：分子约 1×10⁻⁶ m²·s⁻¹，湍流黏性大 3–6 个量级
  • 声速：约 1500 m·s⁻¹，随 T、S、p 增大；声学层析/SOFAR 声道
  • 光：蓝光穿透最深；真光层约 100 m
考点：密度对 T、S 的非线性依赖、α 随温度增大、淡水 4°C 极大密度。

2海洋地理与海底地形

2.1 大洋划分

  • 四大洋：太平洋、大西洋、印度洋、北冰洋（+ 南大洋，约 60°S 以南）
  • 海陆分布：地表 71% 海洋；北半球 61% 水，南半球 81% 水
  • 高程曲线：陆地平均 +840 m，洋底平均 −3800 m

2.2 海底地形分带

地形单元深度范围特征
大陆架0–~130 m坡度小、光照足、生物丰富
大陆坡~130–~2000 m坡度陡，海底峡谷发育
大陆隆~2000–~4000 m浊积扇
深海平原>4000 m极平坦，远洋沉积
大洋中脊全球连贯海底扩张中心
海沟6000–11000 m俯冲带，最深马里亚纳 11034 m

2.3 测深方法

  • 单波束回声测深、多波束（MBES）
  • 侧扫声呐
  • 卫星测高反演海底地形（重力–地形关系）
  • 地震反射剖面（沉积层结构）

3垂直结构与层结

3.1 上层海洋

  • 混合层（Mixed Layer）：风与浮力强迫下充分混合，全球平均深度约 50–100 m
    • 形成机制：风搅拌 + 浮力耗散；Ekman 抽吸 / 混合层模式
  • 季节性温跃层：夏季发育，冬季被卷回混合层
  • 主温跃层：几百米到 ~1000 m，永久性、连接表层与冷水层

3.2 跃层类型

  • 温跃层（thermocline）：dT/dz 极大
  • 盐跃层（halocline）：dS/dz 极大（如北冰洋淡表层下方）
  • 密度跃层（pycnocline）：dρ/dz 极大；往往是温跃层和盐跃层共同贡献

3.3 深层

  • 温度接近 0–4°C，盐度 34.6–34.8
  • 来自高纬深水形成区，年龄由 CFC、C-14 示踪
复习要点：低纬度"三层结构"（混合层—温跃层—深层）；高纬度冬季深对流可达 2000 m。

4基本方程与守恒律

4.1 坐标系与近似

  • 球坐标 → f 平面（f = const）→ β 平面（df/dy = β）
  • Boussinesq 近似：密度变化只在浮力项保留
  • 静力近似：垂直动量方程 → 流体静力方程

4.2 三大守恒方程

1. 质量守恒（连续性方程）

∂u/∂x + ∂v/∂y + ∂w/∂z = 0    （不可压缩）

2. 动量方程（旋转坐标系 Navier-Stokes）

Du/Dt + 2Ω×u = −(1/ρ)∇p + ν∇²u + 其他
  科氏项：f = 2Ω sinφ

3. 热量与盐量守恒

Dθ/Dt = κ_θ ∂²θ/∂z² + Q
DS/Dt = κ_S ∂²S/∂z²

4.3 湍流与雷诺平均

  • 分子黏性 ν ≈ 1×10⁻⁶ m²/s
  • 湍流黏性 A_v ≈ 10⁻³–10⁻² m²/s（混合层）/ 10⁻⁵ m²/s（温跃层）
  • 跨密度面扩散 κ ≈ 10⁻⁵ m²/s（大洋内）；10⁻⁴ m²/s（近地形粗糙区）
核心近似组合：静力 + Boussinesq + f/β 平面 = "原始方程"，几乎所有大洋环流模式的基础。

5海气界面通量

5.1 净热通量分解

Q = Q_s − Q_b − Q_h − Q_e + Q_v
项含义典型量级
Q_s短波入射（吸收）+50–250 W/m²
Q_b长波回辐射−50 W/m²
Q_h感热通量（bulk 公式）−10–25 W/m²
Q_e潜热通量（蒸发）−50–150 W/m²
Q_v平流热输送余项收支闭合
  • bulk 公式：Q_h = ρ_a c_p C_H U (T_s − T_a)
  • 潜热：Q_e = ρ_a L_v C_E U (q_s − q_a)

5.2 风应力

τ = ρ_a C_D |U| U
  ρ_a ≈ 1.2 kg/m³，C_D ≈ 1.0–1.5×10⁻³（随风速增大）
  中性稳定、10 m 高处参考

5.3 淡水通量

  • E − P（蒸发 − 降水）
  • 河川径流 R（侧边界输入）
  • 海冰冻融（高纬）

6地转流与动力海洋学核心理论

6.1 地转平衡（Geostrophy）

  • 大尺度、低 Rossby 数下，科氏力 ≈ 压强梯度力：
f v = (1/ρ) ∂p/∂x ;  −f u = (1/ρ) ∂p/∂y
  → 海流沿等压线流动，北半球右侧高压
  → 由 T、S 计算相对地转流：热成风关系
f ∂u/∂z = (g/ρ₀) ∂ρ/∂y ;  f ∂v/∂z = −(g/ρ₀) ∂ρ/∂x
  • 水平速度参考面需用直接观测（如 LADCP、漂浮物）定零参考层

6.2 Ekman 理论

  • 表层风驱动，忽略水平压强梯度：
  • 表层流偏离风向 右 45°（北半球）/ 左 45°（南半球）
  • 深度增加，速度旋转衰减（Ekman 螺线）
  • Ekman 输送：净输运方向 右偏 90°（NH）
M_E = τ × k / (ρ f)
  • Ekman 抽吸 w_E = curl(τ)/(ρ f)：
    • 正旋度（北半球气旋式风）→ 上升
    • 负旋度（反气旋式风）→ 下降，影响主温跃层深度

6.3 Sverdrup 平衡

β V = curl τ / ρ
  → curl τ 决定内区经向总输运方向
  → 大洋东西尺度由 β/W 决定

6.4 西向强化（Stommel 1948）

  • β 效应要求内区经向输运向极/向赤道流动汇于西边界
  • 西边界流窄而强（湾流、黑潮 ~1–2 m/s，宽 ~100 km）
  • Stommel 模型给出不对称解析解

6.5 涡度与位涡

  • 绝对涡度：ζ + f
  • 位涡守恒：D[(ζ+f)/H]/Dt = 0（无摩擦、绝热）
  • 行星涡度变化 → 相对涡度补偿：等深线流北上时产生反气旋式曲率

7风生环流与水团

7.1 副热带环流圈

  • 反气旋式风（信风 + 西风带）→ Ekman 下沉 → 主温跃层加深
  • "猪槽"（mode water）通风：十八年水（STMW）、亚热带模态水
  • 西边界流回流系统构成闭合副热带环流

7.2 主要表层流系

流系区域特征
赤道流（南北赤道流）5°N–5°S 两侧西向，强而宽
赤道逆流（NECC/SECC）5°–10°东向，逆风
赤道潜流（EUC）赤道 100–200 m东向、强（>1 m/s）
西边界流（湾流/黑潮/巴西/东澳）西边界窄、强、向极
南极绕极流（ACC）50–60°S唯一经向贯通，>100 Sv

7.3 水团分析与 T-S 图

  • T-S 图上水团为固定特征点
  • 中央水：副热带下沉扩散
  • 亚极地水：副极地环流下沉
  • 中层水：南极中层水 AAIW（~900 m）、北极中层水 NPIW、地中海水 MW
  • 深层水：NADW（~2500 m）、南极底层水 AABW（>4000 m）
  • 等密度面分析（isopycnal analysis）追踪通风路径

8热盐环流与经向翻转

8.1 深水形成区

水团形成区特征
NADW北大西洋挪威海、格陵兰海冷咸、~2–4°C
AABW威德尔海、罗斯海极冷、约 −1°C、盐度较高
AAIW南极锋带下沉低盐、富氧

8.2 全球传送带

  • Broecker（1991）"大洋传送带"示意
  • 现代观点：多单元组合
    • 大西洋经向翻转单元 AMOC
    • 南大洋 ACC 连接三大洋
    • 印太太平洋上涌至大西洋闭合

8.3 维持机制

  • 深水形成 ≠ 热盐环流全部
  • 跨密度面混合维持 NADW 上涌回流
  • Munk（1966）一维平衡：w = κ ∂ρ/∂z
  • 南大洋"残留环流"（residual circulation）：风驱动 + 浮力强迫 + 中尺度涡共同作用

9波浪、潮汐与中尺度过程

9.1 表面重力波

  • 色散关系：
    • 深水：ω² = g k
    • 浅水：ω² = g h k²（c = √(gh)）
  • 水质点轨迹：深水为圆，浅水为椭圆
  • 有效波高 H_s：1/3 大波平均；统计符合 Rayleigh 分布
  • 充分成长风浪 → 涌浪（远场传播）

9.2 内波与内潮

  • 等密度面波动，振幅可达数十米
  • 频率范围：N_min < ω < N（Brunt-Väisälä 频率）
  • 内潮：潮汐地形散射产生，深海混合主要来源之一

9.3 行星波

波型存在条件性质
Kelvin 波沿岸/赤道波导沿边界右行（NH）、东向
Poincaré 波旋转海洋含旋转效应的重力波
Rossby 波β > 0西向传播、调整大洋环流
赤道波赤道波导等效 Kelvin/Yanai/Rossby

9.4 潮汐

  • 平衡潮理论：牛顿/拉普拉斯，受天体引力 + 地月公转
  • 动力潮理论：拉普拉斯潮汐方程 + 海盆共振
  • 三类：半日潮（M2, S2）、日潮（K1, O1）、混合潮
  • 调和分析：分潮振幅/迟角 → 预报
  • 强潮混合区：浅海、潮汐河口、海峡

9.5 海啸与风暴潮

  • 海啸：长波（浅水波 c=√(gh)），跨洋速度约 700 km/h
  • 风暴潮：低压 + 风把水推高，台风/飓风沿岸灾害

9.6 中尺度涡

  • 罗斯比变形半径 L_R ≈ c/f ~ 10–100 km（中纬度）
  • 涡动能（EKE）占大洋动能 90% 以上
  • 地转湍流：能量级联从大尺度到次中尺度

B关键公式速查

 1. 状态方程      ρ = ρ(T, S, p)
 2. 位温          θ = T + Γ_d z（绝热修正）
 3. Brunt频率     N² = -(g/ρ)(dρ/dz)
 4. 科氏参数      f = 2Ω sinφ；β = (2Ω/R) cosφ
 5. 地转流        u_g = -(1/(ρf)) ∂p/∂y ;  v_g = (1/(ρf)) ∂p/∂x
 6. 热成风        f ∂u/∂z = (g/ρ₀) ∂ρ/∂y
 7. Ekman输运     M_E = (τ_x, τ_y) × k / (ρ f)
 8. Ekman抽吸     w_E = curl τ / (ρ f)
 9. Sverdrup      β V = curl τ / ρ
10. 位涡守恒     PV = (ζ + f)/H = const
11. 深水色散      c = √(gh)
12. 浅水波速      c² = gh tanh(kh)/(kh)
13. Rossby波速    c_R = -β / k²（长波）
14. 风应力        τ = ρ_a C_D |U| U
15. 净热通量      Q = Q_s − Q_b − Q_h − Q_e + Q_v
16. Munk平衡     w = κ ∂²ρ/∂z²（一维热盐）
